# macOS 快速聊天与文件分流 Demo

本 Demo 使用本地模拟回复，不需要 API Key、账号或远程助手。模型名称、任务状态和附件只用于演示界面；普通文件不会被读取或上传。状态图片会复制到应用数据目录下的 `demo-quick-chat/images`，映射保存在同一命名空间内，不会修改原有角色素材或配置。

## 一分钟演示

1. 将 Demo DMG 拖入“应用程序”并启动 AI Balance Whale；如果 macOS 对未公证的 ad-hoc 签名 App 显示首次打开提示，在 Finder 中按住 Control 点击 App，再选“打开”。
2. 鼠标移到小鲸鱼上，点消息图标；选“深度思考（演示）”，输入“帮我整理今天的安排”并发送，展示“思考中”和本地演示回复。
3. 点“＋ 添加文件”选择两个文件，展示文件名、类型和大小；可以逐个移除。只留附件时也可以直接发送。
4. 从 Finder 把一个文件拖到小鲸鱼，看到接收高亮和“松开发送文件”，松开后展示文件操作浮层。
5. 选“发送至聊天”，确认文件进入待发送附件区，编辑一条消息后再发送。
6. 再拖一个文件，选“交由 AI 助手处理”；选择“提取要点”，补充“关注时间安排”，点击“开始演示”，展示“等待中 → 处理中 → 完成”和“演示结果”。
7. 拖入一张 PNG、JPEG 或 WebP 图片，选“设为交互状态图片”，把它指定给“文件已接收”。再拖文件到小鲸鱼，展示人偶本体切换到这张图片；从“交互图片”按钮也能预览、替换或恢复任一状态图片。
8. 关闭面板，点小鲸鱼确认正常点击；再拖动人偶、打开菜单并调整缩放。

## 交互状态图片

默认、拖入、已接收、处理中和完成状态各有内置样式。导入的图片只支持 PNG、JPEG、WebP，单张最多 20 MiB；应用保存的是复制后的素材，不依赖原图路径。图片映射位于 `demo-quick-chat/state-images.json`，与现有用户角色数据分开。

“总结内容”和“提取要点”只演示任务状态与结果卡，不会读取文件内容。快速聊天回复也由本地演示流程生成；选择的模型名称会显示在回复中。

## 自动化证据与待实机验收

专用 macOS workflow 会启动打包后的 arm64 App，在隔离的 `WHALE_HOME` 中合成输入，检查聊天、附件、文件分流、任务状态、状态图片映射及原生 hit-region 报告，并保存界面截图和诊断日志。合成输入不代表以下项目已经通过：

- 从真实 Finder 拖放普通文件和目录；
- 中文输入法候选期间不发送，以及真实 Shift+Enter 行为；
- 屏幕边缘、不同显示缩放下的面板位置；
- 透明区域对其他 macOS 窗口的实际鼠标穿透。

这些项目仍需在真实 Mac 上人工验收。Demo DMG 使用 ad-hoc 签名，不包含 Apple 公证，也不是正式发布包。
