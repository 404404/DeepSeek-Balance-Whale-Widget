# desktop-demo 演示说明

`desktop-demo` 的聊天回复、模型名称、助手任务状态和附件展示均为本地模拟。它不需要 API Key 或账号；普通附件不会被读取或上传。导入的人偶状态图片会复制到应用数据目录下的 `desktop-demo-quick-chat/images`，映射也保存在此目录，不会修改原有角色素材或配置。

## 启动

- macOS：下载 Apple Silicon DMG，把 `desktop-demo.app` 拖到“应用程序”并启动。未公证的 ad-hoc 签名构建如果被拦截，可在 Finder 中右键 App 并选“打开”。
- Windows：下载 x64 portable ZIP 并解压整个目录，然后运行 `desktop-demo-win32-x64/desktop-demo.exe`。请保留旁边的 `resources` 等运行时文件；单独复制 EXE 无法启动。该构建未签名。

## 一分钟演示

1. 鼠标移到小鲸鱼上，点消息图标；选“深度思考（演示）”，输入“帮我整理今天的安排”并发送，展示“思考中”和本地演示回复。
2. 点“＋ 添加文件”选择两个文件，展示文件名、类型和大小；可逐个移除。只留附件时也可以直接发送。
3. 从桌面把一个文件拖到小鲸鱼，看到接收高亮和“松开发送文件”，松开后展示文件操作浮层。
4. 选“发送至聊天”，确认文件进入待发送附件区，编辑消息后再发送。
5. 再拖一个文件，选“交由 AI 助手处理”；选择“提取要点”，补充“关注时间安排”，点击“开始演示”，展示“等待中 → 处理中 → 完成”和结果卡。
6. 拖入一张 PNG、JPEG 或 WebP 图片，选“设为交互状态图片”，指定给“文件已接收”。再拖文件到小鲸鱼，展示人偶切换到这张图片；也可以从“交互图片”按钮预览、替换或恢复任一状态图片。
7. 关闭面板，测试人偶点击、拖动、菜单和缩放。

## 交互状态图片

默认、拖入、已接收、处理中和完成状态各有内置样式。导入图片只支持 PNG、JPEG、WebP，每张最多 20 MiB。应用保存复制后的素材，不依赖原图路径。图片映射位于 `desktop-demo-quick-chat/state-images.json`，与现有角色素材分开。

“总结内容”和“提取要点”只展示任务状态与结果卡，不会读取文件内容。聊天回复由本地演示流程生成。

## 自动化证据与实机验收

专用 CI 会启动实际打包的 macOS arm64 与 Windows x64 应用，在隔离数据目录中合成输入，检查聊天、附件、文件分流、任务状态、状态图片和窗口输入区域，并保存截图及诊断日志。自动化合成输入不代表真实 Finder/Explorer 拖放、中文输入法或物理鼠标穿透已通过实机验收；这些项目仍需在对应系统上人工复核。
